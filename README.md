# 기능 요구 사항

- 월별 비상근무표 생성 프로그램 만들기

1. 입력 요구 사항

- 월(숫자)과 시작 요일(일, 월, 화, 수, 목, 금, 토) 정보를 입력받는다. (연도는 고려하지 않으며, 매년 2월은 28일까지만 있다고 가정한다)
- 평일 비상 근무 순서를 입력 받는다
- 휴일(토요일, 일요일, 법정공휴일) 비상 근무 순서를 입력받는다.
- 휴일을 다음과 같다 => 1월 1일, 3월 1일, 5월 5일, 6월 6일, 8월 15일, 10월 3일, 10월 9일, 12월 25일

2. 출력 요구 사항

- 평일이면서 법정공휴일의 경우에만 요일 뒤에 (휴일) 표기를 해야 한다. 예를 들어 5월 5일 금(휴일) 루루

# 기능 요구 예외 처리

1. 입력 예외 처리

- 올바르지 않은 입력을 할 경우 [ERROR]로 시작하는 에러 메시지를 출력 후 다시 입력받는다.
- 예를 들어 비상근무 배정할 월과 시작에서 에러갈 났을 경우 비상 근무를 배정할 월과 시작 요일'부터 다시 입력받는다.
- 또한, 평일 순번 또는 휴일 순번의 입력 값이 올바르지 않은 경우, '평일 순번'부터 다시 입력 받는다. 즉, 처음부터 입력 받지 않는다.

1-1) 비상근무 배정 월과 요일 에러 처리

- 빈 문자열일 경우
- 콤마(,)로 월과 요일을 나누지 않았을경우 (ex: 6.월, 6@월)
- '월' 입력 란에 1~12 외에 다른 문자열을 입력할 경우
- '요일' 입력 란에 월~일 외에 다른 문자열을 입력할 경우

1-2) 평일 비상 근무 순번 닉네임 에러 처리

- 근무자 이름은 중복을 할 수 없다.
- 근무자 이름은 최소 1자 최대 5자여야 한다.
- 최소 5명이상 최대 35명 까지만 입력 가능하다.

1-3) 휴일 비상 근무 순번 닉네임 에러 처리

- 근무자 이름은 중복을 할 수 없다.
- 근무자 이름은 최소 1자 최대 5자여야 한다.
- 최소 5명이상 최대 35명 까지만 입력 가능하다.

1-4) 비상 근무일 배정 예외처리

- 근무자는 평일에 한번, 휴일에 한번 사용해야 한다.
- 즉, 평일 순번과 휴일 순번은 동일한 비상 근무자 명단을 사용하되, 순서만 다르게 해야 한다.
  예를 들어 평일 순번: 뜌뜌, 묭이, 토토 이면은 휴일 순번은: 묭이,토토, 연아
- 한 사람이 2틀 연속 근무는 하지 못한다.
  예를 들어 평일 → 평일, 평일 → 휴일, 휴일 → 평일, 휴일 → 휴일
- 순번상 연속 근무가 걸릴 경우 다음 사람과 교체 해야 한다.
  예를 들어 목요일(평일): 묭이, 금요일(휴일): 묭이 이면은 토토와 바꾼다.
  즉, 연속 근무가 처음 생기는 날짜의 근무자를, 같은 순번표에서 바로 다음 사람과 교체한다.

# 프로그래밍 요구 사항

- Node.js 18.17.1 버전에서 실행 가능
- 테스트 성공 시키기
- 함수(메서드)는 한가지만 하게 만들자
- else를 지양한다
- 예외 사항이 발생한 경우 throw를 던져 예외를 발생시킨다.
- @woowacourse/mission-utils에서 제공하는 Console API를 사용하여 구현해야 한다
